# Обновление приложения

Сайт GitHub Pages: https://nekitos9.github.io/tod/ (путь в нижнем регистре).
Локальный запуск: `npm run dev`, затем открыть адрес из терминала с `/tod/`.

## Карточки

Заменить `docs/Паки и вопросы.xlsx` актуальным файлом, затем выполнить
`npm run import:data`. Импорт проверит листы, значения, идентификаторы и токены.
При ошибке исправить указанную строку в Excel и повторить импорт.
Dev-сервер после замены Excel нужно перезапустить. Production build импортирует
таблицу автоматически. `src/generated/game-data.ts` вручную не редактировать.

## Иконка

Исходник — `scripts/assets/app-icon.png`, PNG пользователя без перерисовки.
Чтобы пересоздать размеры на Windows:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-app-icons.ps1
```

Готовые PNG из `public/icons/` хранятся в репозитории, поэтому сборка на GitHub
не требует PowerShell или графических утилит. Фавиконы: 16/32 px, Apple: 180 px,
PWA: 192/512 px. Apple и maskable-вариант имеют непрозрачный фон; буквы исходника
помещаются в центральную безопасную область maskable-иконки.

После перехода с `/ToD/` на `/tod/` старый установленный ярлык может вести на
старый адрес. В таком случае удалить старый ярлык и установить приложение с
нового адреса. Данные игры остаются в localStorage того же домена.

## Проверки

`npm run typecheck`, `npm run lint`, `npm test -- --maxWorkers=1`,
`npm run test:e2e:pwa -- --workers=1`. Последняя команда собирает production-версию
и проверяет её в браузере; работает на Windows и Linux.
